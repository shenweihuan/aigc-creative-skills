## 双层体系

| 层级 | 定位 | 适合谁 |
|---|---|---|
| **QuickStart**（原 v1） | 快速上手，5 分钟出活 | 新手 / 急用 |
| **Domain × Master**（原 v3 核心） | 大师级品味工作流 | 进阶 / 专业创作 |

从 QuickStart 入门 → 熟练后升级到大师层，**一站式体验**。

## 为什么合并？

基于「女娲式品味评审」的核心诊断：

> **"最容易显得重复，最需要重新定位。"**

v1 和 v3 分开让用户困惑"该用哪个"。现在一个仓库内部分层：
- 新手进来直接用 quickstart
- 想深入时自然过渡到大师层
- 不需要做选择，只需要开始用
