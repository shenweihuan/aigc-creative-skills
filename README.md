## 🧠 设计哲学：为什么不是又一个 prompt 合集？

```
普通 AI 教程:  "这是10个prompt技巧"                    ❌
本系统的做法:  "理解为什么 → 建立思维框架 → 技巧自然生长"   ✅
```

每一层都有**底层哲学**支撑：

- 不是教你怎么写 prompt —— 是教你在**人机协作新范式中如何思考**
- 不是教你用 MJ/SD/Sora —— 是教你在**AI时代"看"和"创造"**
- 不是给你工具清单 —— 是帮你建立**自己的判断体系和创作工作流**

**公式：领域底蕴 + AI工具 + 品味判断 = 真正的创作力**

## 🎓 什么时候该"毕业"到 v3？

v1 够用的情况：
- ✅ 快速学会某个具体技能（写prompt / 出图 / 写文案）
- ✅ 日常 AI 辅助创作，需要方法论指导
- ✅ 想建立基础的审美和创意思维框架

建议升级到 v3 的情况：
- 🎨 想深入学习**特定艺术大师的风格体系**（如"用莫奈的印象派眼光评判AI画作"）
- 🎬 想掌握**导演级叙事语言**（王家卫/昆汀的镜头语法）
- ✍️ 想建立**个人化的创作品味系统**，而不只是通用方法论
- 🔬 想要**原子化的大师工作流**（感知训练 → 提示词 → 评价标准 → 跨域迁移）

> **v1 不会消失。** 它是轻量入门的最佳选择。v3 是当你准备好深入时的下一步。

## 📝 设计原则

1. **思想 > 方法** — 每个模块都有底层哲学支撑
2. **领域底蕴 + AI工具** — 不只教操作，更教传统功底
3. **品味训练** — 核心目标是培养判断力
4. **独立可用** — 每个模块都可单独激活
5. **诚实边界** — 明确标注能做到和不能做到的事
6. **持续进化** — v1 稳定可用，思想原型已为 v3 架构升级做好准备
